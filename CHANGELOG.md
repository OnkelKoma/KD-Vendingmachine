# Changelog

All notable changes to this project are documented here.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-13

### Added
- Four machine UI layouts: `soda`, `glass`, `coffee`, `retro`
- Six themes: eCola, Sprunk, Raine, SnackStop, Bean Machine, Redwood
- Walk-up alignment, browse, press and grab animations with hand props
- QBox, QBCore, ESX and standalone (ox_inventory) support
- ox_target, qb-target, ox_lib text UI and native help text interaction
- Per-machine stock with timed restocking and `/restockvending`
- Server-side validation, automatic refunds and Discord webhook logging
- Extra machine placements from the config
- Procedural Web Audio sound effects
- Browser dev preview with mock data
- English and Danish locales
